# UI copy

Read [UI guidance](../../../ui-guidance/README.md). Apply its word limits and punctuation rules to visible product text.

* Name the action or state. Delete repeated explanation.
* Keep transaction amount, token, network, access duration, and required permissions clear.
* Errors: short cause, useful next action. Preserve the real failure meaning.
* Edit display strings only. Preserve SDK messages, identifiers, endpoints, payloads, and user content.

| Replace | Prefer |
| --- | --- |
| Discover APIs that machines can understand | Explore APIs |
| Continue to the provider dashboard | Provider dashboard |
| Your manifest could not be downloaded at this time | Manifest unavailable. Retry. |
| Sign-in | Sign in |
| Machine-readable APIs | APIs for agents |
| APIs — ready to use | Ready to use APIs |

Keep SDK details in development disclosures. Do not rewrite protocol syntax to satisfy prose rules.
