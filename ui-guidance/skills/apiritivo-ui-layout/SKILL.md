# UI layout

Read [UI guidance](../../../ui-guidance/README.md) before editing.

* Inspect the target component and existing shared primitives.
* Reuse live CSS tokens. No copied stylesheet or second theme.
* Flatten panel nesting. Prefer sections, rows, spacing, and dividers.
* Keep necessary field and editor boundaries; remove decorative wrappers.
* Keep one clear primary action. Preserve secondary routes.
* Preserve focus, responsive layout, loading, empty, and error states.
* Preserve event handlers, data hooks, and the persistent Swarm sign in frame.

Apply the current task's testing permissions. Do not trigger login, payment, or publication while arranging UI.
