# ETHRome 2026 sponsor logos

Original logo files downloaded from the [official ETHRome sponsor section](https://www.ethrome.org/#sponsorZone). The source files below are preserved without recoloring or redrawing; light-mode presentation is described separately.

The SVG files include added accessible titles; their paths and colors are unchanged.

`SponsorLogos` shares the artwork between the landing page and documentation on a theme-aware surface. Dark mode uses the original white logos. Light mode uses CSS to display monochrome logos in black and [team1-light.svg](team1-light.svg), a variant that changes only Team1's white lettering to charcoal while preserving its red accent and path geometry.

The repository README uses a self-contained SVG composition at `docs/images/ethrome-sponsors.svg`, with the original artwork on the app's charcoal background for readability in both GitHub themes.

The section identifies sponsors of ETHRome 2026.
